# Apps Script รุ่นเดิม (สำเนาอ้างอิง)
ไฟล์นี้มากับซอร์สหน้าเว็บเดิม เพื่อใช้ตรวจและทดสอบความเข้ากันได้ของ Refresh เท่านั้น
ค่าโฟลเดอร์มาจาก Script property `ROOT_FOLDER_ID` และปิด API ข้อความ/เลขหน้าแบบเดิมที่ไม่ตรวจสิทธิ์รายไฟล์
สำหรับการติดตั้ง OCR และหน้า Reader ให้ใช้ [คู่มือชุดใหม่](../apps-script-ocr/README-TH.md) อย่านำ Code.gs สองรุ่นไปวางในโปรเจกต์เดียวกัน
